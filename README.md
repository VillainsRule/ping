<h2 align='center'>Setup</h2>

1. Install [Go](https://go.dev) & [Bun](https://bun.sh) (node also supported)
2. Clone the repo: `git clone https://github.com/VillainsRule/ping && cd ping`
3. Setup authentication: `bun setup`
4. Prepare for production: `bun run build`
5. Start the production server: `bun start`
